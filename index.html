What is a Variable?

Think of a variable as a labelled box where your program can keep information and use it later.

Start the lesson
let score = 100

📦 score

contains → 100

The simple idea

A labelled box

A variable gives a name to a piece of information. Instead of remembering the value itself, your code can remember its name.

Values can change

Some variables can hold a new value later. This is useful for things like game scores, usernames, counters and shopping-cart totals.

How Variables Work

1

Name it

Choose a clear name such as score.

2

Give it a value

Put information inside with =.

3

Use it

Write the variable name whenever you need that information.
